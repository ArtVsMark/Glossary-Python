# Documentation

[Русский](README.md) · **English**

Documents are grouped by reader — pick the direction first, then the file.

| Direction | For whom |
| --- | --- |
| [`use/`](use/README.en.md) — usage | showcase readers and programs that fetch the data |
| [`dev/`](dev/README.en.md) — development | contributors: build, checks, decisions |
| [`agent/`](agent/README.en.md) — agent work | the agent window: roles, answers to the rule catalogue |

A new document goes inside a direction, not into the root of `docs/`.
Each document has a Russian original `name.md` and an English twin `name.en.md`
with the same structure.
