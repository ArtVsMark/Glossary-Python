# Документация

**Русский** · [English](README.en.md)

Документы разложены по адресату — сначала выбери направление, потом файл.

| Направление | Для кого |
| --- | --- |
| [`use/`](use/README.md) — использование | читатель витрины и программа, забирающая данные |
| [`dev/`](dev/README.md) — разработка | контрибьютор: сборка, проверки, решения |
| [`agent/`](agent/README.md) — работа агента | агентское окно: роли, ответ каталогу правил |

Новый документ создаётся внутри направления, а не в корне `docs/`.

У каждого документа — русский оригинал `имя.md` и английский двойник `имя.en.md`
с той же структурой.
